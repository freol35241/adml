Functions that must be implemented for any struct that uses this derive macro. The only required one is the do_step. The exit_initialization_mode has default behavior.

Can be used to set internal (private) variables based on parameters from the model description file. It Does nothing by default. Can be overridden if some custom initialization behavior is needed
