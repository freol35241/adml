    ($fixed_step:expr) => { ... };
}
Expand description

Generates a do_step method that uses symplectic (semi-implicit) Euler integration with micro-stepping at the given fixed step size.

This is ideal for Hamiltonian systems (pendulums, springs, orbital mechanics) where energy conservation is important.

States must be ordered as [pos_0, vel_0, pos_1, vel_1, ...].
